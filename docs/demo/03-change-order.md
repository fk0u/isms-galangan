# 03. Change Order lewat owner

- **Peran:** Proyek lalu Direktur
- **Data yang dipakai:** Proyek dengan surat BoQ Disetujui.

| Langkah | Klik | Hasil yang diharapkan |
|---|---|---|
| 1 | Tab **Perubahan & Risiko → Ajukan CO**; pilih surat BoQ aktif, tambah baris perubahan (ubah qty / tambah item) | Dampak nilai dihitung otomatis; CO berstatus Diajukan. |
| 2 | Sebagai peran proyek, coba setujui | Tombol tidak tersedia: *Menunggu persetujuan owner*. |
| 3 | Sebagai Direktur: **Setujui → Terapkan** | Revisi BoQ baru dibuat dan disetujui, surat lama Digantikan, anggaran proyek berubah sebesar selisih total. |
