# 13. Hak akses per peran

- **Peran:** Direktur
- **Data yang dipakai:** 14 akun demo (satu per peran).

| Langkah | Klik | Hasil yang diharapkan |
|---|---|---|
| 1 | Tekan **Shift + D** → *Lihat sebagai peran* → Staff Procurement | Sidebar hanya berisi modul procurement. |
| 2 | Pindah ke **Kepala Gudang**, lalu **Client Viewer** | Menu dan data menyesuaikan; simpan sebagai viewer ditolak server (403). |
| 3 | **Kembali ke akun asal** | Kembali sebagai Direktur; perpindahan tercatat di audit. |
